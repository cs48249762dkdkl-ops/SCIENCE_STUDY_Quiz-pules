## 2. 정확성 및 연구 상태
- **관측 확인:** 태양계 행성, 관측된 카이퍼 벨트 천체, IceCube의 고에너지 중성미자 사건.
- **관측으로 지지되는 이론/모형:** 암흑물질의 중력 효과, 일반상대성이론과 블랙홀 모형. 암흑물질 입자 정체는 미확인.
- **가설·미확인:** 오르트 구름의 전체 분포/개별 구성원 직접 관측, 블랙홀 내부 특이점의 물리적 실재, 특정 외계행성 생명 존재.
- **논문 단계:** 동료심사 논문과 arXiv 프리프린트를 명확히 구분. 천체 후보와 확정된 행성 구분.
- 숫자(발견 수·거리·질량)는 기준일, 원천 데이터, 측정 오차, 단위를 함께 기록. 최신 값은 API 조회일 기준 표시.

## 3. 강의 견본: 중성미자와 IceCube
**학습 목표:** (1) 중성미자의 약한 상호작용 설명 (2) 남극 얼음 속 광검출기와 체렌코프광의 관계 이해 (3) 우주선·감마선·중성미자 신호의 차이 비교.
1. 중성미자는 전하가 없고 매우 작은 질량을 가진 기본 입자이며 주로 약한 상호작용을 한다. 태양 핵반응, 대기 중 우주선 충돌, 초신성, 고에너지 천체 환경 등에서 생성된다.
2. IceCube는 남극 깊은 얼음에 배치된 광학 센서로, 중성미자가 얼음 속 물질과 드물게 상호작용해 만든 하전 입자의 체렌코프광을 관측한다. **중성미자 자체를 직접 촬영하는 장치가 아니다.**
3. 방향·에너지 추정에는 광자의 도달 시간과 센서 패턴을 이용한다. 대기 기원 배경 사건과 천체 기원 후보를 통계적으로 구분해야 한다.
4. 실습: 감마선/우주선/중성미자의 전하·상호작용·검출 방식을 비교하고, 실제 IceCube 발표의 관측 신뢰도와 한계를 찾아 표시한다.
5. 복습 질문: (a) 중성미자가 지구를 자주 통과하는 이유는? (b) 체렌코프광은 무엇이 내는가? (c) 배경 사건이 왜 중요한가? (d) 다중신호 관측이란? (e) 사건 하나로 천체 기원을 단정할 수 있는가?
참고: https://icecube.wisc.edu/ ; https://icecube.wisc.edu/science/

## 4. 수식 학습실 기본 명세
- `F=Gm₁m₂/r²` [N]; `T²=4π²a³/G(M+m)` [s²]; `v_esc=√(2GM/r)` [m/s].
- `F=L/(4πd²)` [W/m²]; `L=4πR²σT⁴` [W]; `λ_max=b/T` [m].
- `r_s=2GM/c²` [m]; `E=mc²` [J]; `z=(λ_obs−λ_emit)/λ_emit` [무차원].
- `m−M=5log₁₀(d/10pc)` [등급]; `d(pc)=1/p(arcsec)` [pc]; `v≈H₀d` (저적색편이 근사).
- 심화: 프리드만 방정식 `H²=(8πG/3)ρ−kc²/a²+Λc²/3`; 단위계와 `a`의 정의를 명시.
- 입력값 범위·단위 변환·0/음수·NaN·오버플로 검증. 계산 결과에 공식, 대입, 단위, 유효숫자, 물리적 가정을 표시.
- 예제: 지구 표면 탈출속도 `√(2×6.67430e−11×5.9722e24/6.371e6)≈1.1186e4 m/s≈11.2 km/s`. 공기 저항과 자전 효과를 무시한 근사값.
